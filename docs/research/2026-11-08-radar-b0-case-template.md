# Radar B0：合作决策案例填写模板

**用途：** 还原一条近期真实合作决策及当前流程。每份记录聚焦一个主要决定，可包含连续补料、复核和跟进；不是一个达人档案，也不是一个聊天消息。

**状态：** L0 / C 级研究模板；填写不代表 B0 通过、首发确认或任何决策批准。

填写参考：[虚构案例 DEMO-01](2026-11-08-radar-b0-case-example-fictional.md)。示例全部虚构，仅演示填写方法，不是 Momcozy 业务证据，也不计入真实样本或基线。

## 填写说明

- 先写已知的脱敏摘要，细节按需要补充；不要求首次填写完整时间日志或全部材料。
- 不知道写 `unknown`；不适用写 `NA` 并说明原因。只有核实为零才填 `0`，空白表示尚未填写。
- 人员、合作对象、系统和材料可用别名。不填真实姓名、账号、联系方式、合同正文、报价、凭证或秘密；不记录健康、孕期、儿童或个人粉丝画像等敏感信息。
- 访谈回忆标为 `reported`，不写成现场观察；估算标为 `estimated`，不补造时间戳。
- 空白模板可以留在项目文档中；已填案例仅在获准的研究记录位置保存。原始材料用脱敏摘要或获准引用定位，不要求上传，也不因填写而扩大分享范围。
- 一个案例只用于说明，不证明总体需求或价值；不预设案例数量、市场、品类、岗位或必须有负例。

## 6. 结果与返工

- **当前结果（推进／拒绝／搁置／放弃／截至未决／其他）：**

- **实际引用了哪些材料／版本；如何得知它们进入决定：**
- **实质返工次数及原因（未记录写 unknown）：**
- **补料／复核轮次及原因（与实质返工分开）：**
- **缺证、错误、分歧或质量问题：**

> 实质返工指已有产物因明确问题需要重做或实质修改；复核轮次不自动等于返工。未结束案例标为 `censored`：从触发算到观察截止，不写成已完成耗时。

## 模板依据与边界

- **来源八字段：** source_id = B0-CASE-TEMPLATE-01；evidence_grade = C（L0 研究方法整理）；source_uri = [B0 业务发现工作稿](2026-11-08-radar-b0-business-discovery.md) §6–7；source_owner = 本轮研究助手（非业务批准人）；version = 2026-11-08；workspace = Radar/research；allowed_agents = 本轮文档整理与复核；blocked_actions = 不作需求／首发批准、数据使用许可、真实接入、外联或实施依据。
- **conclusion：** 十字段可填写模板，尚无真实案例输入。
- **evidence：** 上述工作稿 §6–7；不是新增内部事实或真人金标。
- **assumptions：** 用真实近期决定还原当前流程；不假定任务起点或首发选择。
- **uncertainty：** 各案例的内容、来源与权限由实际填写记录确定；当前 unknown。
- **confidence：** 模板与既有研究字段及计时边界对应；业务价值尚未验证。
- **blocked_actions：** 不因填写采集、发送、采购、编码、操作 Git 或部署；D01–D12 仍未批准。
- **next_human_action：** 在获准范围内填写近期真实案例的脱敏摘要，未知留明；没有要求上传原始材料。
